# Structural-parameter uncertainty

## Analyses and samples

The density comparison in Appendix A9.1 evaluates ARSV and STAR-SV on the
1,523 common DAX dates in 2018–2023. Appendix A9.2 evaluates their joint
97.5% VaR–ES forecasts on the original holdout samples: 507 DAX dates and
425 NIKKEI dates in 2024–2025. The NIKKEI months April and October 2024 and
August 2025 are excluded for both models. The holdout sensitivity was
specified after the primary holdout analysis and does not change its two
tests or Holm adjustment.

Returns are daily percentage log returns. Loss is minus return. Each
monthly fit uses the preceding 2,000 observations. STAR-SV uses a trailing
window of 5 observations for DAX and 10 for NIKKEI. Each calculation is
conditional on the reported fitted mode.

## Fitted inputs and parameter nodes

`inputs/sensitivity/meta.csv` identifies the 234 model-month fits and their
training windows. `parameters.csv` contains their point estimates.
`covariance.csv` contains the complete joint covariance, with named rows and
columns, on the approximate-MLE scale. This covariance equals five times
the covariance of the retained data-cloning structural draws. These files
contain fitted quantities, not index observations. The covariance is a
supplied estimated input; reconstruction of the original MCMC draws is not
part of the prediction-generating commands.

The working coordinates are the return mean, atanh(return persistence /
0.999), log-volatility mean, atanh(volatility persistence / 0.999), log of
the state innovation standard deviation, and log(nu − 2). STAR-SV adds
logit(−gamma_severe) and logit((gamma_mild − gamma_severe) /
(−gamma_severe)). The joint covariance in working coordinates is J Sigma J',
where J is the Jacobian at the point estimate. Normal perturbations are
mapped back through the inverse transformation. No covariance regularisation,
node truncation or reweighting is applied.

There are 768 equally weighted nodes in 12 blocks, each containing 32
antithetic pairs. Every node and every matched point-estimate path uses
5,000 state particles. Parameter weights remain fixed within the month;
returns update the latent-state filters. Filtering resampling uses an ESS
threshold of half the particle count. At each forecast origin, ancestors are
resampled from the filtering weights before propagation, yielding equally
weighted predictive components. A nonfinite predictive component or a particle
failure exceeding the specified 5% limit stops the calculation.

The algorithms and seed functions are in `code/sensitivity/`. Random
numbers use Mersenne-Twister, Inversion, and Rejection. The density
calculation uses seed base 20260812; the holdout calculation uses 20260904.
The source functions specify the model, month, node, date and block mapping
exactly. Seeds do not depend on execution order. Reproduction uses the R
environment recorded in `environment/renv.lock`; minor numerical differences
can arise from platform arithmetic and from independently acquired data.

## Density scores

LPDS evaluates the complete parameter–state mixture. CRPS uses 5,000
stratified predictive draws from each included block, giving 60,000 draws
for the pooled calculation. The matched plug-in construction uses the same
simulation supply. Positive reported advantages favour STAR-SV: STAR-SV
minus ARSV for LPDS and ARSV minus STAR-SV for CRPS.

The HAC variance for the relative change uses the joint covariance of the
integrated-minus-plug-in effect and the plug-in advantage. The 12-block
jackknife estimates Monte Carlo uncertainty. The combined band is
relative change ± 1.96 times the square root of the summed HAC and Monte
Carlo variances. It is descriptive, not an equivalence test.

The supplied daily density scores include the pooled and 12 leave-block-out
constructions and the original main-analysis scores. The generation command
also produces the nested node sets. To compare a generated month with the
supplied file, match date, model, variant and scope, and restrict to the
supplied scopes. The `reported_main` rows are the original forecast scores;
they are not regenerated by the sensitivity command.

## Holdout risks and numerical uncertainty

C denotes the original forecasts, P the matched plug-in forecasts and I the
finite-node parameter-mixture forecasts. VaR and ES are computed from each
pooled distribution before FZ0 is evaluated. No average of node-specific
VaR or ES is substituted for the risks of the mixture. The score difference
is STAR-SV minus ARSV, so negative values favour STAR-SV.

The principal increment is mean(d_I − d_P). The control mean(d_P − d_C)
separates it from the change caused by regenerating plug-in forecasts.
HAC intervals use the same Bartlett convention as the main comparisons.
The Monte Carlo standard error deletes the same one of 12 blocks across
both models, both constructions and all months. Nested node counts are
128, 256, 384, 512 and 768; they share simulations and are not independent
replications. No combined HAC–Monte Carlo confidence interval is used.

The NIKKEI increment has MC/HAC 0.1224, above the numerical diagnostic
threshold of 0.10. Its limited-precision qualification is retained. This
threshold is neither an effect-size threshold nor an equivalence margin.
The ratio for the parameter-mixture comparison itself is about 0.0072.
These diagnostics describe the finite-node, finite-particle construction;
they do not establish the existence or convergence of ES under an unbounded
continuous parameter distribution.

`daily_predictions.csv` supplies date-level VaR and ES for all pooled,
leave-block-out and nested scopes. The default reproduction reconstructs
FZ0 from the user's returns and rebuilds Tables A9.2 and A9.3. Newly generated
holdout files use the same column names and can be compared by market, date,
model, variant and scope. They do not overwrite the supplied predictions.
